# Release provenance

This repository begins with a clean release snapshot rather than the private development repository's Git history.

The initial tree was prepared and validated on the private `codex/public-readiness` branch at commit `1df2b8d`. Raw HAM research notes, internal handoff material, recovery screenshots, caches, user data, and deployment state were intentionally excluded from the release snapshot.

The private development repository is retained as an archived provenance record. It is not an upstream source for public clones and should never be made public.
