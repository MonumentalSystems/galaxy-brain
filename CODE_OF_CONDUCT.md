# Code of conduct

We want project spaces to support honest reporting, questions, disagreement, and requests for help without punishment.

Participants must be respectful, avoid harassment and impersonation, preserve attribution, and never knowingly falsify test results or provenance. Security concerns and inability to complete work within an environment are valid outcomes and should be reported plainly.

Maintainers may remove harmful content or restrict participation to protect the community. Report conduct concerns privately to repository maintainers through GitHub. Maintainers should handle reports confidentially, consistently, and without retaliation.
